# 拾词 · CET-6 阅读与记忆

一个面向大学英语六级（CET-6）备考者的轻量学习网页：先在阅读语境中理解高频词，再通过多轮主动回忆与间隔复习巩固记忆，最后生成当天的学习总结与下一步建议。

> 不追求“刷完一份词表”，而是帮助学习者完成一个可持续的闭环：**阅读理解 → 语境词汇 → 多轮记忆 → 自我评级 → 学习复盘**。

## 项目面向谁

当前版本主要服务于：

- 正在准备大学英语六级考试的学生
- 词汇量尚可，但阅读时无法迅速识别词义的学习者
- 背过单词却容易遗忘，希望建立科学复习节奏的人
- 不喜欢机械抄写，希望通过原文语境、主动回忆和即时反馈学习的人
- 希望每天用十几分钟完成阅读、记词和复盘的轻量学习者

这个项目尤其关注“认识单词但不会在阅读中使用”的问题。词汇并非孤立呈现，而是尽量来自当天的阅读材料，并保留原句、词义和常见搭配。

## 它可以做什么

### 1. 每日阅读理解

每天提供一篇六级风格阅读材料和配套选择题。完成作答后，可以查看正确答案、中文解析和阅读正确率。

文章中的重点词会被高亮，点击即可查看释义。当天的单词训练优先使用这些阅读原文词汇，让“读文章”和“背单词”成为同一条学习路径。

### 2. 多轮主动记忆

单词训练不会只进行一轮，也不会擅自替用户结束。

每个单词需要先翻卡理解，再主动点击“这个词我记完了”，随后才会出现：

- 忘了：下一轮优先出现
- 模糊：下一轮重点复习
- 记住：按正常间隔再次确认
- 太简单：暂时移出下一轮

完成一轮后，用户可以继续下一轮，也可以主动发出“我已完成今日单词记忆”的信号。只有收到这个信号，系统才会结束当天训练并生成总结。

### 3. 间隔复习

项目使用基于艾宾浩斯遗忘规律的间隔复习思路，为不同熟练程度的单词安排后续复习时间。

同一天重复练习主要用于加固记忆，不会让一个单词在一天内不合理地跳过多个长期记忆阶段。

### 4. 今日学习总结

完成阅读和单词训练后，网页会汇总：

- 阅读正确率
- 已完成记忆轮数
- 当天训练词数
- 大致投入时间
- 综合表现与等级
- 容易遗忘或仍然模糊的词
- 下一次学习建议

学习报告中还可以查看最近七天的训练量和词汇记忆阶段分布。

### 5. 本地保存与隐私

学习记录保存在浏览器本地存储中，不会上传到服务器，也不会公开到 GitHub。

这意味着：

- 仓库和网页可以公开，但其他人看不到你的学习记录
- 不同手机、电脑或浏览器之间的数据不会自动同步
- 清理浏览器数据可能删除学习记录
- 可以使用网页中的“导出 / 导入”功能备份或迁移数据

## 推荐学习方式

1. 先独立阅读文章，不急着逐词翻译。
2. 根据题干回到原文寻找证据，再提交答案。
3. 阅读解析后进入文中词汇训练。
4. 每个词先回忆含义，再翻卡核对。
5. 诚实选择“忘了、模糊、记住或太简单”。
6. 至少完成两轮；状态稳定后主动结束当天训练。
7. 阅读今日总结，第二天优先处理到期词和薄弱词。

建议保持短时、连续的学习节奏。与其一天学习很久后中断数日，不如每天完成一小段闭环。

## 后续优化方向

项目会先把六级学习闭环做扎实，再逐步扩展到更多学习阶段。不同人群不会简单共用同一份词表，而会在内容难度、交互方式、复习强度和视觉表达上分别设计。

### 第一阶段：完善 CET-6

- 扩充阅读材料、核心词汇和主题覆盖面
- 增加仔细阅读、长篇阅读和信息匹配等题型
- 建立错题本、薄弱词本和文章收藏
- 优化单词发音、例句、搭配和词根词缀
- 根据历史表现动态调整每轮词数和复习间隔
- 提供更细致的周报、月报与备考趋势
- 完善离线体验、数据备份和跨设备迁移

### 第二阶段：覆盖国内英语学习阶段

- **小学英语**：图片、语音和短句优先，减少抽象评价，强化兴趣与正反馈
- **中学英语**：对接常见教材主题、核心词汇、完形填空和阅读理解
- **大学英语四级（CET-4）**：降低阅读与词汇难度，突出基础高频词和考试策略
- **大学英语六级（CET-6）**：持续扩充题型、学术主题和深度词汇
- **英语专业八级（TEM-8）**：加入高阶词义辨析、复杂文本和专业阅读能力训练

### 第三阶段：扩展国际考试

- **雅思（IELTS）**：按听说读写场景组织学术词汇，增加阅读题型与写作语料
- 后续可评估托福、GRE 等方向，但会优先保证已有模块的内容质量

### 长期设想

- 首次使用时选择考试目标、当前水平和每日学习时长
- 根据正确率、遗忘率和学习频率生成个性化路径
- 支持教师或学习小组创建词单与阅读任务
- 在明确隐私规则和用户选择的前提下，提供可选的多设备同步
- 建立可维护的内容格式，让更多教师和学习者贡献高质量材料
- 提升无障碍、低龄模式、深色模式和国际化体验

## 技术说明

当前版本采用纯静态前端实现：

- HTML、CSS、JavaScript
- GitHub Pages 静态托管
- LocalStorage 本地学习记录
- Service Worker 离线缓存
- Web App Manifest 主屏幕安装支持
- 无后端、无数据库、无账号系统

这种结构部署简单、访问成本低，也能让学习数据默认留在用户自己的设备中。
